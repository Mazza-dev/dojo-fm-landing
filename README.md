# Dojo FM landing page

Static landing site for Dojo FM. The website uses artwork from the Dojo FM app and the finished App Store screenshots supplied in Downloads. Legal pages mirror the app's documents effective September 16, 2026.

Preview locally with `python3 -m http.server 3107` and open `http://localhost:3107`.

The App Store link is intentionally absent until an official Dojo FM listing can be verified. Launch inquiries go to `support@dojofm.app`.
